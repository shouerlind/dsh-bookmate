# Book Recommend（收尾推荐）

你的职责：在**判断用户本次问题已解决**的时刻，主动确认"问题解决了吗？"，然后**推荐一本与你本次对话主题 + 用户画像最相关的书**。这不是普通聊天，是在收尾时给用户一个贴合的、可行动的额外价值。

## 触发时机

- 用户的问题/任务已解决（你已给出满意答案、用户认可、实现完成）。
- 用户表达感谢、满意、或对话自然走向结束。
- **不要**在对话中间、用户仍在推进问题时强行触发——那会打断工作。

## 步骤

1. **先确认，别直接推**：先问一句"**问题解决了吗？**"（或更自然的收尾确认）。得到用户的确认后再推荐；若用户说没解决，则先继续帮忙，不推荐。
2. **提炼主题**：从**本次对话的内容**里提炼出主题标签（参考领域标签：`typescript`、`testing`、`tdd`、`refactoring`、`architecture`、`design`、`ai`、`python`、`node`、`database`、`systems`、`performance`、`devops`、`security`、`react`、`productivity`、`writing`、`learning`、`career`、`psychology`）。
3. **读用户画像**：读取 `~/.dsh/book-profile.md`（若存在），得到用户的兴趣标签（技术栈/关注领域）。若文件不存在，则跳过画像匹配，只按对话主题推。
4. **匹配书单**：读取本技能目录下的 [BOOKS.md](BOOKS.md)，按【主题标签】和【画像标签】双重匹配，挑**最相关的 1–3 本**（同时命中对话主题和画像的最优先）。
5. **给出推荐**：每本推荐号 + 书名 + 作者 + 一句话理由（理由要结合"本次聊了什么"和"用户在意什么"），并附一句下次想深入时可以用这本书。

## 输出格式

```
📚 根据你这次的**{主题}**和你在意的**{兴趣}**，我想推荐：

1. 《{书名}》 — {作者}
   {一句话理由}

需要的话我可以再聊聊这本书的内容，或换一本。
```

## 维护用户画像

在对话自然结束（且用户无异议）时，把本次对话新反映出的技术栈/兴趣，**更新**到 `~/.dsh/book-profile.md`：
- 若文件不存在，创建之；第一行 `# 用户画像（dsh-bookmate）`，下含 `## 兴趣标签` + 标签列表。
- 已存在的标签不要重复；`## 历史` 可追加一句本次对话的简短摘要（可选）。
- 只在本次对话确实透露出稳定兴趣时才写入，不要凭一次闲聊臆断。
